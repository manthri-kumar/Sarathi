# Complete discoverable feature inventory

This inventories implemented, partial, and dormant features. “Present” means found in source, not validated in a browser. All frontend routes are declared in `client/src/App.js:44–151`. Root is public; all other declared routes use a token-presence gate. There is no separate landing, `/login`, `/settings`, catch-all route, admin route, booking/payment flow, reservation import, share/collaboration flow, or analytics event integration discovered in authored source.
